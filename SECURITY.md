# Security Policy

## Supported Versions

We are committed to ensuring the security of Kotlin AutoMapper. Security patches and updates are provided for the most recent major release.

| Version | Supported          |
|---------| ------------------ |
| **0.x** | :white_check_mark: |


## Reporting a Vulnerability

The security of our users is a top priority. We appreciate your efforts to responsibly disclose your findings, and we will make every effort to acknowledge your contributions.

To report a security vulnerability, please use the **[private vulnerability reporting feature on GitHub](https://github.com/jacksever/kotlin-automapper/security/advisories/new)**.

This is the fastest and most secure way to reach us. Please **do not** report security vulnerabilities through public GitHub issues, discussions, or other public channels.
